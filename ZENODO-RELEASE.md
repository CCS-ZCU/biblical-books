### 2. Create a Git Tag
Choose a semantic version. For the initial release with stable harvest data, use `0.1.0`:

```bash
git tag -a v0.1.0 -m "Initial release: K10plus Biblical Studies harvest (525,205 records, 2026-11-18)"
git push origin v0.1.0
```

1. Go to: https://github.com/kasev/biblical-books/releases/new

3. Release title: `v0.1.0: K10plus Biblical Studies Bibliography Harvest`

## 4. Connect to Zenodo

### Option A: Automatic via GitHub Integration (Recommended)

1. Go to Zenodo: https://zenodo.org
2. Log in with your GitHub account (or create one)
3. Go to: https://zenodo.org/account/settings/github/
4. Toggle **biblical-books** to ON
5. The release will be archived automatically within 24 hours

### Option B: Manual Upload to Zenodo

1. Download the release as ZIP from GitHub
2. Go to Zenodo: https://zenodo.org/deposit/
3. Upload files and fill in metadata
4. The .zenodo.json file will be used to populate fields
5. Publish the deposition

## Troubleshooting

### "License not recognized by Zenodo"
Zenodo expects the SPDX identifier. Use `CC-BY-SA-4.0` (hyphens, capital letters).

### "Title too long or keywords invalid"
Keep title under 300 characters. Keywords should be single words or short phrases, separated by commas.

### "GitHub didn't auto-archive"
- Verify the .zenodo.json file is valid JSON (use an online JSON validator)
- Ensure it's at the repository root (not in a subfolder)
- Wait 24 hours; Zenodo checks GitHub releases periodically
- Manually upload if needed

### "ORCID not recognized"
Use the full URL: `https://orcid.org/0000-0002-6601-1605` or just the ID: `0000-0002-6601-1605`
